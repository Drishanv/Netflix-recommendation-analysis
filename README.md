# 🎬 Netflix Movie Recommendation System

A content-based recommendation engine built using the **Netflix Movies & TV Shows dataset**. This system recommends similar titles by analyzing **descriptions, genres, casts, and directors** with **TF-IDF vectorization** and **cosine similarity**.

---

## 📘 Project Overview
- **Objective:** Recommend movies or TV shows similar to a selected title based on content similarity.  
- **Dataset:** Netflix Titles dataset (`netflix_titles.csv`).  
- **Approach:**  
  - Text preprocessing and normalization.  
  - TF-IDF vectorization of combined metadata (`title`, `director`, `cast`, `listed_in`, `description`).  
  - Cosine similarity to find the most similar titles.

---

## 🧠 Methodology
1. **Data Cleaning**
   - Remove duplicates and handle missing values.  
   - Normalize text fields (lowercase, trim spaces).  

2. **Feature Engineering**
   - Create a new column `content_text` combining `title`, `director`, `cast`, `listed_in`, and `description`.

3. **Vectorization**
   - Apply **TF-IDF Vectorizer** to convert text into numerical features.  
   - Limit vocabulary size to `100,000` and remove English stop words.

4. **Similarity Calculation**
   - Compute **cosine similarity** matrix on TF-IDF vectors.  
   - Retrieve the top 10 most similar titles for each selected show or movie.
